ArtWorth AI — Intelligent Valuation for Sculptural Artifacts

ArtWorth AI predicts a relative value index for sculptural artworks based on material, artist signals, age, dimensions, provenance and historical sale information. Results are presented as an index (relative score), plus a tier (Low / Medium / High) and a confidence estimate.

Know the Context Before Forecasting

What is Art Valuation? It is the process of estimating the relative financial worth of artworks based on tangible and intangible factors.

What is ArtWorth AI? A machine learning based system that learns from historical auction data, material, size, artist reputation, and provenance to predict a relative valuation index.

How does the model work? Input features are normalized and passed through trained ML models (Random Forest / Gradient Boosting). The model outputs an abstract index score.

Input Features: Artist reputation, dimensions, material, provenance, age, previous auction price, etc.

Who benefits? Auction houses, art galleries, museums, collectors, and students studying art economics.

What does the output mean? The output is a Relative Value Index (not currency). High index = more valuable; low index = less valuable.
