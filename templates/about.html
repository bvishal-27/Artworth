About the Project

ArtWorth AI is an intelligent system designed to predict a relative valuation index for sculptural artworks.

The model integrates historical sales records, material analysis, artist reputation, artwork age, and cultural significance to generate a comparative index score. This approach avoids currency misinterpretation and provides a reliable benchmark for curators, collectors, and researchers.

Key highlights:

  • Uses advanced machine learning ensemble models for accuracy above 90%.
  • Outputs a relative index score, valuation tier (Low, Medium, High), and confidence estimate.
  • Provides interpretability with factors influencing predictions and recommendations for value improvement.
  • Assists galleries, auction houses, students, and hobbyists in preliminary valuation tasks.
